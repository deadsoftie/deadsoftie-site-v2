Quire.

A clunky local‑first LaTeX editor. Compiles offline, no TeX install required: built in the open for research and education.

v1.0.1 MIT licensed macOS · Linux

about

Quire compiles LaTeX locally and offline: no system TeX Live or MiKTeX install to fight with, no network fetch required to get a document open and building. Write with real completion for labels, citations, macros, and packages, and watch the PDF preview update page by page as you save.

A small curated package set ships in the app so common documents compile clean out of the box; anything else installs on demand, with no separate package manager to wrestle with. An optional system TeX fallback is there too, for anyone who already has a full install and wants to use it instead.

Open source and MIT licensed, built as a tool for research and education: free to use, study, and modify for coursework, papers, and teaching material.
